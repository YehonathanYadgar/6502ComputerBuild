### Project Goals

- The final PC build should match the PC shown in Part 7 of the Ben Eater videos.
- Cables should be relativley organized, but not necessarily to the same degree as Ben Eater's examples.
- Maintain an organized GitHub repository, including:
    - Personal notes
    - System overview
    - Progress pictures (if available)
    - Code files from various stages, with comments
    - A markdown file (README) explaining the project
- Achieve a solid low level understanding of the system, improve general knowledge of computers, and advance your skills in electronics.
