# Original build photos

These are byte-for-byte copies preserved before photo cleanup on 2026-09-20.

The photos in this folder are stored locally and ignored by Git. They are not included in new clones; only this README is tracked.

- `img1.jpeg` through `img5.jpeg`: original repository photos.
- `finished-computer.png`: first uploaded photo of the completed build.

The images one directory above use conventional crops, rotation, small brightness/saturation adjustments, and mild sharpening. No components or wires were generated or retouched. Framing follows the breadboards while keeping the build wiring visible; the original camera perspectives are retained. The video files were not edited.

To restore a photo, copy its original from this folder over the edited counterpart. The finished photo is published as `../finished-computer.jpeg` using a full-resolution crop of a 5712 × 4284 HEIC original. The untouched HEIC is backed up locally; the earlier PNG upload remains here. The published JPEG has photo metadata removed.
