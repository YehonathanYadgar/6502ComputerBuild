# Original build photos

These are byte-for-byte copies preserved before photo cleanup on 2026-09-20.

- `img1.jpeg` through `img5.jpeg`: original repository photos.
- `finished-computer.png`: original uploaded photo of the completed build.

The images one directory above use conventional crops, rotation, small brightness/saturation adjustments, and mild sharpening. No components or wires were generated or retouched. Framing follows the breadboards while keeping the build wiring visible; the original camera perspectives are retained. The video files were not edited.

To restore a photo, copy its original from this folder over the edited counterpart. The finished photo is published as `../finished-computer.jpeg`; its untouched source remains PNG here.
